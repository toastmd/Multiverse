# MULTIVERSE MUD art prompts

573 images. Generate each in any text-to-image tool (Midjourney, DALL-E, Stable Diffusion, Flux...), save it as `<key>.png` or `.jpg` (for example `player-magician-f.jpg`), put all files in one folder, then run:

    python3 tools/import_art.py path/to/folder

The importer crops and resizes each file to the right shape and installs it. Rebuild the guide afterwards with `node tools/build_guide.js` if you changed guide images.

Negative prompt for every image: `cartoon, illustration, drawing, painting, anime, 3d render, cgi, plastic skin, text, watermark, logo`

Tips: use the same style words and one seed or style reference per group (portraits, landscapes) so the set looks consistent. Make terrain textures seamless/tileable. Portraits should be tall (5:6), banners very wide (4:1), landscapes 5:2.

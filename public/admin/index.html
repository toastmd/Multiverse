Admin commands only work when you are logged in as an Administrator; anyone else who types them just gets "What?". Commands are typed in the game's command line like any other. Where a player's name is needed, capitalization does not matter.

Moderation: keeping the game friendly

Tools for dealing with trouble, from a quiet word to a permanent ban. Use the lightest one that works.

silence <player>

Ten minutes with no tells, gossips or shouts. The player can still play, fight and read, so it is a cooling-off period, not a punishment. Only works on someone who is online. Administrators and the resident bots cannot be silenced.

Silence Troublemaker
> Troublemaker is silenced for 10 minutes.
(they see: An administrator has silenced you for about 10 more minute(s): no tells, gossips or shouts.)

unsilence <player>

Ends a silence early.

unsilence Troublemaker
> Troublemaker is no longer silenced.

ban <player|ip>

Blocks an IP address from logging in, and disconnects everyone on it right now. Give a player name (their last login address is used) or an address. Refused for the local machine (127.0.0.1 / ::1, which would lock out everyone playing on the host) and for any address an Administrator is using. Bans are saved in data/bans.json and survive restarts. If the game runs behind a reverse proxy, start it with TRUST_PROXY=1 so the real visitor address (X-Forwarded-For) is used; without it every visitor looks like the proxy.

ban Troublemaker
> Banned 203.0.113.9 (Troublemaker's address). Anyone on it is disconnected and cannot log in.
ban 198.51.100.4
> Banned 198.51.100.4.

bans

Lists every banned address with who banned it and when.

bans
> Banned addresses:
>   203.0.113.9 (Troublemaker) banned by Joe on 2026-10-21 20:54

unban <ip|player>

Lifts a ban, by address or by the player whose address it was.

unban 203.0.113.9
> Unbanned 203.0.113.9.
unban Troublemaker

purge <player>

Permanently deletes a player's character (save file and mudmail), online or offline. They are disconnected and may register the name again from scratch. Refuses Administrators (take the role away first with admin remove) and yourself (use deleteme). This cannot be undone: there is no backup unless you keep one (see Backups below).

purge Troublemaker
> Troublemaker has been purged: character, mudmail and all.

Roles: who can do what

There are three ranks. Players play. Architects may also use the area builder. Administrators (wizards) have everything on this page. The first account created on a brand-new server is an Administrator automatically.

admin add <player> | admin remove <player> | admin list

Make someone an Administrator or remove the rank. Works for offline players. You cannot remove yourself, and there must always be at least one Administrator.

admin list
> Administrators: Joe. Architects: Ben.
admin add ben
admin remove ben

architect add <player> | architect remove <player> | architect list

Give or take away the builder rank (Architect). Architects get the grid area builder but none of the other admin powers.

architect add ben
> Ben is now an Architect.
architect list

builder

Shows the link and private key of the GUI area builder (also at the address printed when the server starts). Architects and Administrators only. Areas you build get a milestone automatically and can be synced to GitHub.

builder
> Area builder: http://localhost:4000/builder.html   key: ********

World: testing and running

Everything for looking around the game as a builder or tester.

goto <room id>

Teleports you to any room by its id (area/room). Handy for testing a boss or checking a new area.

goto modern/t10_c
> (you arrive in the CEO's Office)
goto cave/throne
goto town/square

clone <item id>

Creates any item in your pack by its id.

clone goldenparachute
clone mammothsteak
clone ironsword

update

Reloads the world data (rooms, mobs, items, quests) without restarting. Players are not disconnected.

update

shutdown confirm | shutdown cancel

Saves everyone and stops the server after a countdown; `shutdown cancel` stops it.

shutdown confirm
shutdown cancel

Integrations

Optional services. The game runs fine with none of them; set them up in data/config.json (see below).

discord

Shows whether the Discord bridge is connected.

discord

github

Shows the GitHub sync status (builder saves, ideas and bugs).

github

tweet [test]

Shows the X/Twitter status; `tweet test` posts a test message.

tweet
tweet test

Also for administrators

bounty post

Posts a bounty immediately. Only one bounty is active at a time (the next one appears about 30 seconds after one is collected or expires), so this says so when one is already up.

bounty post
> Bounty posted.

who, finger <player>, deaths, leaderboard

Normal commands that help moderation: who is online, a player's details (class, level, email if they made it visible), the death tally with killers, and the top-10 board.

finger troublemaker
deaths 30
deaths top

Bug and idea reports

Players' idea and bug commands are filed on GitHub (as markdown plus an issue assigned to the repository owner) when GitHub is configured, and queued in data/reports/ with automatic retry when it is not.

Configuration: data/config.json

Never synced to GitHub. Every block is optional.

{
  "giphy":   { "apiKey": "...", "rating": "pg", "cooldownSeconds": 6 },   gossip GIFs
  "discord": { "webhookUrl": "..." },                                      MUD -> Discord
  "github":  { "token": "...", "repo": "owner/Repo", "branch": "main", "assignee": "owner" },
  "pixabay": { "apiKey": "..." },                                          art fetching tool
  "smtp":    { "host": "smtp.example.com", "port": 587, "secure": false, "user": "...", "pass": "...", "from": "mud@example.com", "fromName": "MULTIVERSE MUD" },
  "resetMinutes": 30                                                       room reset interval
}

Environment variables: PORT (default 4000), TRUST_PROXY=1 (use X-Forwarded-For for ban addresses), SMTP_* (override the smtp block), GIPHY_API_KEY, GITHUB_TOKEN.

Recipes

A player is spamming gossip

silence Spammer        (10 minutes, they can still play)
silence Spammer        (again, if they come back and do it again)
ban Spammer            (if it keeps happening)

Someone keeps coming back after a ban

The ban is by IP address. A new account from the same address still cannot log in. If they use a different network, ban that address too (bans shows what you have).

Removing an account for good

purge Troublemaker     (character and mudmail gone, name free again)
ban Troublemaker       (do this BEFORE purge: the address comes from their saved record)

Handing over the keys

admin add ben
admin list
admin remove joe       (only works while someone else is an Administrator)

Testing a boss

goto modern/t10_c      the CEO's office, 4 aggressive monsters
clone goldenparachute  check the unique item
goto cave/throne       Grog the Great

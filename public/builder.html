Monsters you create

Stats (HP, damage, XP, credits, drops) are generated from the level, same as the built-in monsters. You can also use any existing monster id in a room.

How to use

  • Paint: click an empty cell to make a room; with auto-link it connects to neighbours.
  • Link: click two adjacent rooms to toggle the exit.
  • Erase: click a room (or right-click anywhere).
  • Connect to the existing world with an external link in the room editor.
  • Rooms on other floors: use the floor buttons, then set Up/Down links in the editor.

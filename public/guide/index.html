Welcome to the MULTIVERSE MUD Player's Guide. MULTIVERSE MUD is a browser MUD where fantasy, sci-fi and the Old West collide: hunt monsters, run contracts across a dozen realms, craft and gather, install cyberware, and be reborn up to forty times. This guide is organised by type, so you can find what you need quickly.

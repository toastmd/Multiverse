Triggers (saved to your character)
When a line of game text contains the text (or matches /regex/), your command runs. Separate several commands with ; and use $1 for a captured group. Tick the last box to highlight the line. Chat lines never fire triggers. Also: the trigger command.
Edit keypad keys (saved to your character)
Type a command for each key; separate several with ; (for example: look;score). Works with Num Lock on whenever the command line is empty. Also: the keypad command.
